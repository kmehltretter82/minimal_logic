We prove the structural lemma of p. 114, lines 3–13. Let $r$ be a $\beta$-normal term of type $0\to 0$ whose free variables lie among $F_1,\dots,F_k$ of type $\nu=(0\to0)\to(0\to0)$ and $\alpha$ of type $0\to0$. Then:

$$\text{(i) every subterm of } r \text{ has type } 0,\ 0\to 0 \text{ or } \nu;\qquad \text{(ii) every subterm of type } \nu \text{ is some } F_i;$$

$$\text{(iii) every subterm of type } 0\to0 \text{ is generated by clauses (1)–(3).}$$

**Idea.** In a normal term every application has a variable at its head. The only variables available are the $F_i$, $\alpha$, and bound variables, and the types of the $F_i$ and $\alpha$ force every bound variable to have type $0$. We track this with an invariant on subterm occurrences.

**The invariant.** Call a variable *allowed* if it is an $F_i$, equals $\alpha$, or has type $0$. Write $\mathrm{Good}(t,\tau)$ if all of the following hold:

- $t$ is normal and has type $\tau$;
- every free variable of $t$ is allowed;
- $t$ is an abstraction only when $\tau\in\{0,\,0\to0\}$.

Then $\mathrm{Good}(r,0\to0)$ holds by hypothesis.

**Neutral terms.** Let $t$ be a normal term that is not an abstraction and has allowed free variables. By induction on $t$, its type is $\nu$ (and then $t=F_i$), $0\to0$, or $0$. For a variable, this is the allowed-variable condition. For an application $t_1t_2$, normality makes $t_1$ a non-abstraction. By induction its type $\sigma\to\tau$ is $\nu$ or $0\to0$, so $\tau$ is $0\to0$ or $0$.

**The invariant passes to subterms.**

- *Applications.* In $t_1t_2$ the function part is neutral. Its type is $\nu$ or $0\to 0$, so the argument has type $0\to0$ or $0$.
- *Abstractions.* An abstraction $\lambda x.b$ of type $0\to0$ forces $x$ to have type $0$, which is allowed, and $b$ to have type $0$.

By induction on the subterm relation, every subterm $s$ of $r$ satisfies $\mathrm{Good}(s,\sigma)$ for some $\sigma$. By uniqueness of types in this Church-style calculus, $\sigma$ is the type of $s$.

**Shapes.** By induction on $t$, the invariant gives the following:

- At type $0\to0$, $t$ satisfies clauses (1)–(3).
  - A variable must be $\alpha$.
  - An application must be $F_i\,s$, and $s$ is again of type $0\to0$.
  - An abstraction $\lambda y.b$ has a body $b$ of type $0$.
- At type $0$, $t$ is a chain $s_1(\dots(s_q z)\dots)$ of basic terms ending in a variable $z$ of type $0$.

These give (iii). Statements (i) and (ii) follow from the invariant and the neutral-term lemma.

The proof is constructive and uses only `propext` and `Quot.sound`.
